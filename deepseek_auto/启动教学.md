# deepseek_auto 启动教学

从零到跑起来的完整步骤。按顺序做，每步都有验证方法。

---

## 一、环境准备（只做一次）

### 1. 安装 Python 依赖

```powershell
cd C:\Users\ziqin\Desktop\work_files\deepseek_auto
pip install -r requirements.txt
```

依赖清单：`uiautomator2`（手机控制）、`requests`、`Pillow`、`numpy`、`opencv-python-headless`（验证图定位）。

### 2. 启动雷电模拟器并确认 adb 连接

```powershell
adb devices
```

应看到类似 `emulator-5554   device` 的一行。看不到就检查：模拟器是否已启动、雷电设置里 adb 调试是否开启。

### 3. 模拟器里安装并打开一次 DeepSeek App

确认包名是 `com.deepseek.chat`，能正常打开到聊天界面。

## 二、配置（只做一次）

### 1. 填入千问 API Key（人机验证的命脉）

打开项目目录下的 `.env` 文件，填三项：

```ini
QWEN_API_KEY=你的key
QWEN_BASE_URL=中转站给你的接口地址（如 https://xxx.com/v1）
QWEN_MODEL=qwen-vl-max
```

> ⚠️ 你的 key 已实测**不是**阿里云官方 DashScope 的 key（官方返回 403），必须向发 key 的平台要到 **BaseURL** 填上，否则人机验证无法破解。

### 2. 检查 config.py 里的服务端地址

| 配置项 | 说明 | 默认 |
|---|---|---|
| `SERVER_BASE_URL` | FastAPI 短信服务（收验证码） | `http://172.28.108.138:8000` |
| `RPA_SERVICE_URL` | 后台任务认领/心跳 | `http://localhost:8084` |
| `BACKEND_BASE_URL` | 结果回调/截图上传 | `http://localhost:8080` |

跑 FastAPI / 后台的机器不在本机时，改成对应 IP（也可用同名环境变量覆盖）。

### 3. 添加手机号

```powershell
python run.py --add 13800138000
python run.py --add 13900139001
python run.py --list      # 查看号池
```

## 三、自检（每次开跑前建议做）

```powershell
python run.py --check
```

逐项看输出：

- ✅ FastAPI OK —— 短信服务通
- ✅ 手机号池: N 个号 —— 号池非空
- ✅ adb 设备 —— 模拟器已连
- ✅ 千问 VL 已配置 —— .env 已生效（只校验非空，连通性看第四节）
- ⚠️ RPA 不可达 —— 本地测试可忽略，正式跑必须通

### 验证千问真的能用（可选但强烈建议）

填好 `.env` 后跑一句：

```powershell
python -c "from config import QWEN_API_KEY,QWEN_BASE_URL,QWEN_MODEL; import requests; r=requests.post(QWEN_BASE_URL.rstrip('/')+'/chat/completions', json={'model':QWEN_MODEL,'messages':[{'role':'user','content':'hi'}],'max_tokens':5}, headers={'Authorization':'Bearer '+QWEN_API_KEY}, timeout=30); print(r.status_code, r.text[:120])"
```

返回 `200` 即配置正确；`401/403` 说明 BaseURL 或模型名不对。

## 四、本地冒烟测试（强烈建议正式跑之前做）

```powershell
python run.py --once
```

它会完整走一遍：**登出 → 选号 → 登录（含人机验证破解）→ 问 1 题 → 打印回答**。

请**盯着模拟器屏幕**观察：

1. 左侧抽屉是否被点开、三个点是否点中 → 设置页是否退出成功
2. 「发送验证码」点击后，验证弹窗是否被识别、点击位置是否准确
3. 点错不用慌：脚本会自动解刷新后的新题（最多 3 轮）

验证过程的截图存在 `screenshots\captcha_debug\`（`_marked.png` 上绿十字就是 AI 点的位置），点偏了拿图来找我调。

如果某一步点偏（比如抽屉按钮、三个点），把当时界面发我，我用精确锚点替换坐标兜底。

## 五、正式运行

```powershell
python run.py
```

运行逻辑：登录 → 从后台认领任务 → 问答采集 → 截图上传+结果回调 → 每号满 10 题自动登出换号 → 循环。`Ctrl+C` 优雅退出（自动归还在跑任务）。

## 七、常见报错速查

| 报错 | 原因与处理 |
|---|---|
| `没连到任何 Android 设备` | 模拟器没启动 / adb 未连接，先 `adb devices` 确认 |
| `手机号池空` | 先 `--add` 加号 |
| `未配置 QWEN_API_KEY` | `.env` 没填或文件名不对（必须在项目根目录、名字就是 `.env`） |
| `人机验证多次尝试未通过` | 先看 `screenshots\captcha_debug\` 的图：坐标偏→联系我调；模型答非所问→查 BaseURL/模型名 |
| `轮询验证码失败/超时` | FastAPI 短信服务没收到码：查 `SERVER_BASE_URL`、手机信号、是否触发频繁发送限制 |
| `登录后未进入已登录状态` | 截图发我，可能是版本 UI 变动 |
